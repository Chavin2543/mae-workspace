# The H1 deck is now a hand-edited master — never regenerate it

- **Date:** 2026-07-25
- **Decided by:** Mae
- **Status:** active

## Context
The deck was generated by scripts/management_deck/build_deck.js. Mae edited
the pptx directly in PowerPoint (50 slides: new Bangkok/Pattaya
"Tourist Arrivals + Spending power" slides at positions 10-13, "Us vs our
compsets" moved before the ADR-challenge slide) and asked to use her file
as the working master.

## Decision
output/Portfolio_Performance_Report_H1-2026.pptx is the single working
master. All future deck changes are surgical edits to this pptx
(python-pptx). Never re-run build_deck.js over it — regeneration would
destroy her manual edits. The script stays for reference only (warning in
its header).

## Consequences
- Data refreshes (new months, corrected June arrivals) get patched into the
  existing slides, not rebuilt.
- extract_deck_data.py remains useful for computing figures to patch in.
